# Current BioSynvia specifications

Effective expanded editions dated November 5, 2026:

- [PRD v1.2](BioSynvia_PRD_v1.2.pdf)
- [SRD v0.2](BioSynvia_SRD_v0.2.pdf)

Each PDF contains its controlling revision first, then the complete unchanged
baseline. The precedence tables identify which baseline scope/status clauses are
updated. All original requirement IDs and gates remain traceable. Earlier PDFs
are preserved as historical baselines and must not be mistaken for the current
scope. The `.md` files contain the editable controlling revisions; the retained
baseline PDFs provide the remainder of each edition.

The PRD adds DT-01 through DT-10. The SRD adds SR-DT-001 through SR-DT-021 and
acceptance specifications T-019 through T-034. All new requirements are proposed,
not claims of implemented or scientifically validated capabilities.

Track A retains the V1 offline soft-sensor workbench. Track B adds reusable
research modeling components, characterization, simulation/integration and
conditional extension outcomes. Neither is an operational Digital Twin claim.

Revision content and layout checks are recorded in the implementation report.
