# Public repository scope

This is the public portfolio copy of the BioSynvia engineering checkpoint.
It includes project code, tests, synthetic examples, requirements/specifications,
selected analytical reports, scientific evidence notes and review records.

The publisher dataset, backups, processed CSV/SQLite bundles, high-cardinality
value enumerations and source-cell observation exports remain local. Dataset
reuse terms are unresolved, so the archive is not redistributed here. Download
information and fingerprints are recorded in the project provenance reports.
Some report links intentionally refer to local generated artifacts; reproduce
those after obtaining the source dataset and preparing the versioned bundle.

The public synthetic demonstration and core tests require no source dataset.
Analysis/integration tests require their documented dependencies; released-v6
checks additionally require the local bundle. Historical logs and manifests are
preserved as dated evidence rather than claims of current scientific approval.

The EGM files under `integrations/egm` retain their upstream Apache-2.0 license
and attribution. The manuscript viewer captures cite the CC BY preprint in the
scientific source register. No license is inferred for the separate dataset.
Personal plugin-installation records and credentials are excluded.
